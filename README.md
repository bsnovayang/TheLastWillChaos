# The Last Will & Chaos

豪門遺產爭奪戰的黑色喜劇文字策略遊戲。五天後宣讀遺囑，在那之前，你要設局、套話、挑撥，或者……帶著女僕連夜跑路。

一局約 30 分鐘，15 種結局，沒有唯一的正解。

## 怎麼玩

- 用瀏覽器打開 `index.html` 就可以玩（不需要安裝任何東西）
- 點人物對話、下指令；點 ✦ 調查物件
- 下指令或「動手」調查會花一個時段；移動、閒聊、看東西不花時間
- 按住 **Ctrl** 可以快轉對話，**Space / Enter** 翻頁
- 遊戲會自動存檔，關掉網頁後可以從標題畫面「繼續」

## 檔案結構

| 想改什麼 | 檔案 |
|---|---|
| 劇情、事件、結局 | `src/data/story.js` |
| 對白（語氣、話題、回應選項） | `src/data/dialogue.js` |
| 家族群組的訊息 | `src/data/group.js` |
| 數值、作息、金錢 | `src/data/world.js` |
| 規則 | `src/game/engine.js` |
| 角色點陣圖 | `src/chars/*.js` |
| 房間背景（pxl 原始碼） | `art/*.px.js` → 輸出到 `assets/` |

設計文件：`企劃書.md`、`角色設計.md`、`結局設計.md`、`開發清單.md`
